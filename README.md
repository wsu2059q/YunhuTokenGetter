# Yunhu Token Getter

![GitHub Actions Workflow Status](https://img.shields.io/github/actions/workflow/status/wsu2059q/YunhuTokenGetter/deploy.yml?style=flat-square)

纯前端实现的云湖用户登录工具，用于获取访问令牌（Token）及展示用户信息。

### 在线使用

访问 GitHub Pages：https://get-yh-token.erisdev.com

### 登录方式
> 支持使用以下方式登录获取token：

#### 邮箱登录
- 输入邮箱地址
- 输入密码
- 点击登录

#### 短信登录
- 输入手机号码
- 点击"获取验证码"按钮
- 完成人机验证（输入图片验证码）
- 输入收到的短信验证码
- 点击登录

## 隐私

**本工具完全在浏览器本地运行，不收集、存储或上传任何用户数据。**

- 所有数据（包括邮箱、密码、Token、用户信息）仅存储在您的浏览器本地（localStorage）
- 不会向任何第三方服务器发送您的登录信息
- 仅与云湖官方 API 通信以获取 Token 和用户信息
- 您可以随时清除浏览器数据，所有信息将被完全删除
- 源代码完全开源，您可以自行审查
